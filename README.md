# Genesis-IT-Homelab Overview

This homelab was created to expand my knowledge and develop hands-on experience in Systems Administration, Networking, and IT Infrastructure Management. What initially started as an idea has evolved into a functional virtualized environment where I can deploy, configure, manage, and troubleshoot various systems and services.

The environment currently consists of two Dell OptiPlex PCs running Proxmox VE, configured as a two-node virtualization cluster. Across both hosts, I have deployed 8 virtual machines (6 currently running) and 3 containers, each serving different purposes within the infrastructure.

Through this homelab, I have gained practical experience with virtualization, Windows and Linux administration, networking, infrastructure monitoring, and troubleshooting.

This repository documents the projects, configurations, challenges, and solutions I have encountered while building and maintaining my environment. Each project folder contains information about the technologies used, implementation steps, and lessons learned.
